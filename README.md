# Troot Window\n\nPublic-first job marketplace built with React, TypeScript, Vite, Capacitor, ASP.NET Core 9 and SQL Server. Workers can browse jobs without an account. Employer submissions enter moderation as PendingReview.\n\n## Production\nHost the ASP.NET Core API and SQL Server database separately from the frontend. Put the SmarterASP.NET SQL connection string in hosting configuration, never Git. Add EF migrations before first deployment.\n\n## Trust & safety\nVerification must be an actual moderation process, not an automatic badge. Add admin moderation, employer verification, expiry/closure, reports, audit logs, anti-spam and abuse controls before unrestricted public posting.\n\n## Ads\nOnly inline, clearly labelled sponsored slots. Never cover navigation, forms, contact buttons or job content; never use pop-ups, forced redirects, autoplay audio or fake Apply buttons.\n
