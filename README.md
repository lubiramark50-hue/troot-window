# Troot Window

Troot Window is a human-centered employment marketplace.

Stack: React + TypeScript + Vite, Capacitor Android, ASP.NET Core/C#.

Capacitor application ID: ug.troot.window

Brand: Navy #18324A, Coral #E76F51, Mint #74C69D.

The design intentionally avoids generic AI gradients, excessive glassmorphism, fake statistics, fake testimonials, decorative AI effects and non-functional controls. Neumorphism is restrained and accessibility-conscious.

Android release workflow generates the native Capacitor Android platform and builds a release APK.
